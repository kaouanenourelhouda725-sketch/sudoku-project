# Sudoku Project

## Project Description
This project is a simple Sudoku solver written in C language.

## How it Works
The program uses a basic backtracking method to solve a 9x9 Sudoku grid.
Empty cells are represented by 0.

## How to Run
1. Compile the program:
   gcc main.c -o sudoku
2. Run the program:
   sudoku/.

## Features
- Solves a 9x9 Sudoku
- Simple and easy to understand
- Written in C language
