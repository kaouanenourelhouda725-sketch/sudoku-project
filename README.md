# sudoku-project# Sudoku Solver Project

## Project Description
This project is a Sudoku Solver implemented in C language.
The program takes a 9x9 Sudoku grid as input, where empty cells are represented by 0,
and solves the puzzle using a backtracking algorithm.

## How It Works
The program scans the Sudoku grid to find empty cells.
For each empty cell, it tries numbers from 1 to 9.
If a number is valid according to Sudoku rules, it is placed in the cell.
If no valid number can be placed, the algorithm backtracks and tries another solution.

## Features
- Accepts a 9x9 Sudoku grid
- Uses backtracking algorithm
- Displays the solved Sudoku grid
- Handles unsolvable puzzles

## How to Run
1. Compile the program using a C compiler:
 gcc main.c -o sudoku
2. Run the program:
   sudoku/.
